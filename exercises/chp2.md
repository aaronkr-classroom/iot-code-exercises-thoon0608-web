# chp2 연습문제

1. 이 책에서는 마이크로파이썬 IDE로서 Thonny를 사용하고 있지만, 여러 가지 IDE가 존재합니다. 마이크로파이썬 IDE를 추가로 2개 이상 조사하고, Thonny와 장단점을 비교하세요.

| IDE명 | 장점 | 단점 | Thonny와의 비교 |
|:---|:---|:---|:---|
| **VS Code**<br>(MicroPython 확장) | - 코드 자동 완성, 문법 하이라이팅 등 강력한 에디터 기능<br>- Git 연동이 매우 편리하여 버전 관리에 탁월함<br>- 다양한 확장 프로그램 지원 | - 초기 환경 설정(플러그인, 포트 설정 등)이 초보자에게 복잡함<br>- 프로그램 자체가 상대적으로 무거움 | Thonny가 '입문/실습용'이라면, VS Code는 '실무/대규모 프로젝트용'임.<br>깃허브(Git) 연동 과제를 수행하기에는 VS Code가 훨씬 유리함. |
| **Mu Editor** | - 인터페이스가 직관적이고 단순하여 코딩 입문자에게 최적화됨<br>- 마이크로파이썬 및 교육용 보드와 호환성이 좋음 | - 고급 디버깅이나 프로젝트 관리 기능이 부족함<br>- 복잡한 구조의 코드를 작성하기에는 기능이 제한적임 | Thonny보다 더 단순한 구조임.<br>Thonny는 파일 탐색기 등 실습에 필요한 부가 기능을 적절히 갖추고 있어 Mu Editor보다 활용도가 높음. |

2. 마이크로파이썬의 펌웨어를 올리기 위해서 부팅할 때 별도의 버튼을 클릭하게 합니다. 해당 절차의 필요성을 설명하세요.

3. REPL 모드에서, 마이크로파이썬에서 사용할 수 있는 모듈의 리스트와 그에 속한 함수나 클래스를 표시하는 명령어를 각각 나열하세요.
